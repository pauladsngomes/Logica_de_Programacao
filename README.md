# Calculadora Simples

## Sobre o projeto

Este projeto foi desenvolvido como parte das atividades do curso de Lógica de Programação.

A calculadora foi desenvolvida em Shell Script (Bash) e permite realizar operações matemáticas básicas entre dois números.

## Operações disponíveis

- Adição (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

## Como executar

Para executar o arquivo `calculadora.sh`, é necessário utilizar um ambiente Linux com o Bash e o comando `bc` instalados.

Primeiro, altere a permissão do arquivo para torná-lo executável:

```bash
chmod 744 calculadora.sh
