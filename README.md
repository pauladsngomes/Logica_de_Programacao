# Calculadora Simples

## Sobre o projeto

Este projeto foi desenvolvido como parte das atividades do curso de **Lógica de Programação**.

A calculadora foi desenvolvida em **Shell Script (Bash)** e permite realizar operações matemáticas básicas entre dois números.

## Operações disponíveis

* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)

## Tecnologias utilizadas

* Linux
* Shell Script (Bash)
* Git
* GitHub

## Como executar o projeto

Primeiro, clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Depois, acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

Dê permissão de execução ao arquivo:

```bash
chmod +x calculadora.sh
```

Execute o programa:

```bash
./calculadora.sh
```

## Funcionamento

Ao executar o programa, o usuário deverá informar dois números.

Em seguida, deverá escolher uma das operações disponíveis:

1. Adição
2. Subtração
3. Multiplicação
4. Divisão

O programa realiza o cálculo e apresenta o resultado na tela.

## Exemplo de execução

```text
=================================
       CALCULADORA SIMPLES
=================================

Digite o primeiro número: 10
Digite o segundo número: 5

Escolha uma operação:
1 - Adição
2 - Subtração
3 - Multiplicação
4 - Divisão

Digite a opção desejada: 1

Resultado: 15
```

## Validações

O programa possui validações para evitar erros durante a execução, como:

* Verificação dos números informados pelo usuário.
* Verificação da opção escolhida no menu.
* Tratamento da divisão por zero.
* Mensagens de orientação para o usuário.

* Variáveis
* Entrada de dados

* Operadores matemáticos
